# Полка

Учебное фронтенд-приложение курса: каркас админки «Полка». Сейчас это стартовая страница на Vite, чтобы проверить сборку, алиас `@` на папку `src` и линтер.

## Стек

- React
- JavaScript
- Vite
- ESLint

## Установка и запуск

```bash
npm install
npm run dev
```

Проверка кода:

```bash
npm run lint
```
